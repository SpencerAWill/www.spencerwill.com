# www.spencerwill.com

My personal public website.

Built with [TanStack Start](https://tanstack.com/start), Tailwind CSS v4 and
Biome, deployed to Cloudflare.

```sh
pnpm install
pnpm dev        # http://localhost:5173
pnpm build
pnpm check      # lint + format
pnpm typecheck
```
